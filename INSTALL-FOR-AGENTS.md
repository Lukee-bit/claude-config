# Instructions for a coding agent (Claude Code, Claude, Codex, ...)

If a user gives you this repository's link, use it as the source of their setup. Do this in order.

0. **Fastest path:** `pwsh ./setup/setup.ps1 -All -Yes` (Windows) or `./setup/setup.sh --all --yes` (macOS). It installs the prerequisites, configures every harness already on the machine (`-Only claude,cursor,opencode` to name them and install missing ones) and prints a PASS/FAIL table. Humans just double-click `Install.cmd` / `Install.command`. Add `-DryRun` / `--dry-run` first to show what it would do. If every check passes, skip step 1.
1. **First install on this machine** (no `~/.claude-tools/config-repo` file): clone the repo, read `README.md` (macOS) or `windows/README.md` (Windows), then run the installer for the OS with `--dry-run` / `-DryRun` first and show the user what it would do:
   - macOS: `./install.sh --dry-run`, then `./install.sh`
   - Windows 11 (PowerShell 7): `pwsh ./install.ps1 -DryRun`, then `pwsh ./install.ps1`
   Finish the manual steps listed at the end of the installer output and in the README, then run `mcptoon doctor`.
2. **Optional surfaces** (after the base install):
   - **Cursor / Cursor Code** (macOS + Windows): read `cursor/README.md`, then `./install-cursor.sh` or `pwsh ./install-cursor.ps1` (use `--dry-run` / `-DryRun` first). Fully quit and restart Cursor afterward.
   - **OpenCode V2**: read `opencode/README.md`, then `./install-opencode.sh` or `pwsh ./install-opencode.ps1`.
3. **Already installed**: do not reinstall. Run `~/.claude-tools/bin/config-sync status`. If it reports newer commits, read the pending `CHANGELOG.md` entries, tell the user, and with their OK run `/config-update` (or `config-sync apply`, then each manual action the entries list, then verify).
4. Installers back up anything they replace as `*.bak-YYYYMMDD`. Never commit secrets; `export.py` refuses output that looks like one.
5. One source of truth: tools, hooks, MCP servers, plugins and services are defined in `claude/`, `mcptoon/`, `launchd/`, `skills/`, `bin/`, `tools/`. Windows output is generated by `windows/render.py`; OpenCode by `opencode/render.py`; Cursor by `cursor/render.py`. Change the templates, never the generated files on one machine.

Updates are manual: run `/config-update` (Claude Code and OpenCode) or `~/.claude-tools/bin/config-sync status` to see and apply what changed. Nothing checks at startup.
